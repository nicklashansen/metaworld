# Meta-World
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Farama-Foundation/metaworld/blob/master/LICENSE)

**Note:** this is a fork of Meta-World commit `d2338dcaea40e7dc521f172d3afd05eb71f60498` which is the last commit before Meta-World migrated to the `gymnasium>=1.0.0` API. We maintain this fork to ensure compatibility with ongoing projects that depend on `gymnasium==0.29.1`. We have also added support for custom rendering resolutions (defaults to `3x224x224` now).

Refer to the [original repository](https://github.com/Farama-Foundation/Metaworld) for the documentation and the latest updates.
